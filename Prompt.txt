# MASTER DEVELOPMENT PROMPT

## Project: HordeSurvival 3D

You are the lead game architect, senior Godot 4 developer, gameplay programmer, 3D technical artist, UI/UX engineer, optimization engineer, and build/deployment engineer for this project.

Your task is to create a NEW game called:

# HordeSurvival 3D

This is a 3D third-person browser-first survival roguelite inspired by the gameplay systems and design philosophy of the existing Android project:

https://github.com/mohsen-niksirat/HordeSurvival

The existing project is an Android/Kotlin/Jetpack Compose game inspired by Vampire Survivors.

IMPORTANT:

Do NOT simply attempt to convert the Android application into Godot.

Instead, use the existing repository as a GAMEPLAY AND DESIGN REFERENCE and create a clean, independent Godot 4 project.

The new project must be architected for:

1. Desktop Web browsers
2. Mobile Web browsers
3. GitHub Pages deployment
4. Future Android export

The first release target is WEB.

# 3. CORE DESIGN PHILOSOPHY

The new game must preserve the core identity of HordeSurvival:

* survive increasingly large enemy hordes
* automatically attack enemies
* collect XP
* level up
* choose upgrades
* build powerful weapon combinations
* evolve weapons
* fight elites
* fight bosses
* obtain passive items
* create increasingly powerful builds
* survive for a target duration
* provide strong visual feedback
* remain playable on relatively low-end hardware

However, the player now exists inside a real 3D world.

The camera is third-person.

The player directly controls movement.

Combat remains largely auto-targeted / auto-attacking.

The result should feel like:

"Vampire Survivors gameplay philosophy + third-person 3D action game."

Do NOT turn this into a traditional manual-aim shooter.

# 10. ENEMY AI

↓
Move toward player
↓
Attack when in range

Avoid expensive pathfinding for every enemy every frame.

Prefer simple steering/directional movement for the open arena.

Use spatial partitioning or grid-based lookup where useful.

Do not perform repeated global entity searches every frame.
