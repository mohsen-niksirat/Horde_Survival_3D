## ۱) بوت، بارگذاری و منو

- [ ] صفحهی لودینگ ظاهر میشود و نوار پیشرفت به ۱۰۰٪ میرسد (بدون گیر کردن)
- [ ] «Click to Play» فقط بعد از کلیک/لمس بازی را شروع میکند و صدا از همان لحظه کار میکند
- [ ] منوی اصلی باز میشود: Play / Characters / Achievements / Settings / How to Play
- [ ] تنظیمات صدا (Master/Music/SFX) تغییر میکند و بعد از رفرش صفحه **ذخیره میماند**
- [ ] «How to Play» محتوای درستی نشان میدهد
- [ ] دکمهی Start → ورود به انتخاب کاراکتر → ورود به بازی بدون خطا

| دامنهی پیچ دوربین (−۶۰ تا −۱۵ درجه) آزاردهنده نیست | | |

| گیمپد (اگر داری): استیک چپ حرکت، استیک راست دوربین، تریگرها ابلیتیها | | |

## ۳) کنترل — موبایل (فقط وقتی موبایل داری)

- [ ] جویاستیک مجازی سمت چپ: حرکت **فوری** شروع میشود ولی پرش ندارد (deadzone درست است)
- [ ] حس حرکت با دسکتاپ همارز است (نه کُندتر، نه بیشازحد سریع)
- [ ] درگ سمت راست صفحه دوربین را نرم و بدون جهش میچرخاند؛ حساسیت اطراف لبهها طبیعی است
- [ ] دکمههای ابلیتی و Pause بهاندازهی کافی بزرگاند (حداقل ~۴۸px) و درست لمس میشوند
- [ ] HUD داخل ناچ/سوراخ سلفی گوشی نمیافتد (safe-area)
- [ ] در جهت افقی و عمودی هر دو قابل بازی است (افقیتوصیه: افقی)
- [ ] لمس همزمان جویاستیک + درگ دوربین + دکمه ابلیتی تداخلی ندارد

## ۴) HUD

- [ ] HP bar، XP bar، Level، تایمر، Kills، Combo همه قابل خواندناند
- [ ] آیکونهای سلاحها نشان میدهد چه سلاحهایی داری و چند تیرش را (۱–۵) دارا هستی
- [ ] ردیف ارتقا (Level-Up) بازی را pause میکند و ۳–۴ کارت بدون تکراریِ بیمصرف میدهد
- [ ] رنگبندی نایابی کارتها (C/U/R/L) واضح است
- [ ] رلیکها و پت (Dragon Welp) در HUD دیده میشوند
- [ ] کولداون ابلیتیها واضح است
- [ ] ویگنت HP پایین (low-HP) دیده میشود ولی خوانایی صفحه را از بین نمیبرد
- [ ] در صفحههای باریک موبایل هیچ عنصری همپوشانی ندارد (مثلاً بنر باس روی XP bar)

## ۵) گیمپلی و بالانس (سناریوی ۱۵ دقیقهای)

> توصیه: یک ران کامل ۱۵ دقیقهای برو و هر بازه را جدا بررسی کن.

| بازه | انتظار | چک | یادداشت |
|---|---|---|---|
| ۰–۲ دقیقه | فقط Droneها، سلاح اول اتوماتیک کار میکند، کشتن رضایتبخش است | | |
| ۲–۵ دقیقه | Wisp / Swarm / Turret اضافه میشوند؛ فشار حس میشود ولی منصفانه است | | |
| ۵–۱۰ دقیقه | Tankها و الیتها (رنگ طلایی + ۱–۲ توانایی) ظاهر میشوند | | |
| ۱۰–۱۵ دقیقه | تراکم بالا، باس در موعد (نزدیک ۵ دقیقه/سطح ۲۵) با بنر هشدار | | |
| کل ران | سطح ~۲۵ تا دقیقهی ۱۰ (سرعت ارتقا نه کُند نه بیدردسر) | | |

- [ ] هر ۵ سلاح (Fireball، Magic Missile، Shield، Spear، Lightning) حس متفاوتی دارند
- [ ] ارتقای هر سلاح تا تیر ۵ محسوس است
- [ ] اِوولوشن (Hellfire، Holy Bible) فقط در «تیر ۵ + پسیو مکس» پیشنهاد میشود و حس ×۳ دارد
- [ ] گزینههای ارتقا هرگز «مرده» نیستند (حداقل یک گزینه همیشه مفید است)
- [ ] اوربهای XP مگنت میشوند و جمعکردنشان لذتبخش است
- [ ] الیتها: تلپورت/شیلد/انفجار/هیل/اسپلیت… همگی قابل تشخیص و واکنشپذیرند
- [ ] باس: فاز ۱ (تعقیب + ضربهی زمینی با حلقهی تلگراف) → فاز ۲ (والی + سامون) → آنریج (<۲۵٪) درست تغییر میکند
- [ ] پت (Dragon Welp) دنبال میکند و شلیک میکند
- [ ] رلیکها (با نایابی رنگی) روی نقشه ظاهر میشوند و مگنت/برداشتنشان درست است
- [ ] کومبو و ضریب XP با کشتن پیدرپی بالا میرود و تیرهای رنگی اعلام میشوند
- [ ] مردن → صفحهی Results با آمار و طلا → Play Again / Menu بدون باگ

## ۶) حس بازی و بازخورد (Juice)

- [ ] دمیج نامبرها ظاهر میشوند (کریت طلایی) و تعدادشان زیاد نمیشود (باجت)
- [ ] فلش ضربه (hit flash) روی دشمن دیده میشود
- [ ] مرگ دشمنها انفجار/بورست رضایتبخش دارد (نه «ذوب شدن»)
- [ ] اسکرین شیک در ضربه/باس هست ولی شدتش قابل تحمل است
- [ ] لحظهی Level-Up حس «لحظهی بزرگ» دارد (رینگ + افکت + ورود کارتها)
- [ ] تریل سلاحها و افکت AOE (حلقهی تلگراف روی زمین) واضح است
- [ ] صداها: هر سلاح صدای متفاوت دارد؛ XP، Level-Up، هشدار باس، مرگ — هیچ صدایی تکراری/آزاردهنده نیست
- [ ] موسیقی با شدت بازی تغییر میکند (آرام → پرتنش → باس) اگر پیاده شده باشد

## ۸) وب اختصاصی

- [ ] رفرش صفحه در وسط ران → همهچیز از نو شروع میشود (state بازی ذخیره نمیشود — درست است)
- [ ] طلای متا، دستاوردها و رکوردها بعد از رفرش **میمانند** (IndexedDB)
- [ ] دستاوردها فقط یک بار فعال میشوند (نه تکراری)
- [ ] اگر WebGL غیرفعال باشد، پیام fallback مناسب نشان داده میشود
- [ ] PWA: نصب/آفلاین شل (اختیاری — اگر پیاده شده)
